# GitHub 공개 저장소 운영

기준일: 2026-10-28.

## 목적과 공개 범위

- 저장소: [vosyd12/Rhythm](https://github.com/vosyd12/Rhythm)
- 사용자가 공개(Public) 저장소를 직접 생성하고 업로드를 승인했다.
- 현재 프로젝트를 포트폴리오용 기술 데모의 기반으로 보관한다. Boot와 관련 실행 의존성이 현재 개발 범위이며, 완성된 배포 게임으로 소개하지 않는다.
- 현재 소스·씬·에셋·패키지 잠금 파일·프로젝트 설정·문서를 포함한다. 캠프 등 기존 의존 코드를 공개 준비를 이유로 삭제하거나 재작성하지 않는다.

## 공개 업로드에서 제외

- Unity 캐시·로그·임시 검증 사본·복구 사본·IDE 생성물·사용자 설정.
- 로컬 자동화 설정, 원시 JSONL, 장치별 파일 해시 목록과 원본 보관본의 내부 조사 자료.
- 시험용 MP3와 그 `.meta`. 해당 파일은 로컬에 유지하며, 재배포 권한을 확인하기 전에는 공개하지 않는다. 공개 사본은 보유 음원 선택 방식으로 실행한다.

`.gitignore`와 업로드 파일 목록을 함께 확인한다. `.meta`·기존 GUID와 원본 소스 인코딩·개행은 보존한다. 비밀정보 검사에서 검출된 값은 보고서나 콘솔에 그대로 출력하지 않는다.

## 포트폴리오 설명 기준

- README에서 기능·주요 소스·실행 방법·개발 상태·검증 한계를 구분한다.
- 사용자 정상 작동 확인을 자동화 테스트 통과·벤치마크 결과로 확대하지 않는다.
- 외부 폰트·TMP 샘플 등은 직접 제작한 기능으로 소개하지 않고 원본 고지·라이선스를 유지한다.
- 별도 프로젝트 라이선스나 GitHub Pages 배포는 이번 업로드에 포함하지 않는다.
