# 폴더별 관리 기준

## 문서 분류

| 폴더 | 관리하는 내용 | 목록 파일 |
|---|---|---|
| `작업관리` | 현재 목표, 범위, 관리 규칙 | `README.md` |
| `검증결과` | 결함 보고, 수정 후 검증, 실행 증거 | `README.md` |
| `변경기록` | 변경 이력 | `README.md` |
| `참고자료` | 원본 보관본의 설명·무결성·참조 조사 기록 | `README.md` |

## 새 파일 작성 규칙

1. 내용에 맞는 기존 분류 폴더를 먼저 선택한다.
2. 새 문서용 폴더 이름은 한글, 파일 이름은 영문으로 작성한다. 예: `검증결과/BootFixVerification.md`.
3. 분류 폴더마다 `README.md`를 목록으로 두고 파일의 목적·현재 상태를 짧게 기재한다. 새 파일을 만들거나 이동하면 목록도 함께 갱신한다.
4. 같은 내용의 문서를 중복 생성하지 않는다. 과거 검증은 당시 기록으로 남기고, 현재 상태와 후속 결과를 링크한다.
5. 새로운 분류가 지속적으로 필요할 때만 한글 폴더를 만들고 이 표에 등록한다.

## Unity 파일

`Assets`, `Packages`, `ProjectSettings`와 기존 코드·에셋의 폴더명은 Unity 참조를 보존하기 위해 유지한다. 문서 분류를 이유로 씬·스크립트·에셋을 이동하거나 GUID를 변경하지 않는다. 실행용 임시 자료와 복구 사본은 `Temp` 아래에 두며, 계속 참고해야 할 최종 결과는 해당 문서 분류 폴더로 옮긴다.
