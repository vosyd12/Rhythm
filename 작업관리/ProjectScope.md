# Boot 작업 범위와 목표

기준일: 2026-10-28. 사용자가 확정한 현재 범위를 기록한다.

## 확정 범위

- 지금의 구현·수정·실행 검증은 `Assets/Scenes/Boot.unity`와 그 실행에 필요한 리듬·음원·UI·연출 의존성에 한정한다.
- 현재 결함을 먼저 해결해 음원 선택, 분석, 박자 선택, 리듬 플레이를 점검할 수 있는 기반을 만든다.
- 기존 리듬 동작과 직렬화 참조를 보존하고, 캠프·전투·캠페인을 새로 개발하거나 변경하지 않는다.
- 기존에 삭제한 GAME_DESIGN·MILESTONES 문서는 읽거나 복구하지 않는다. 이후 작업 범위는 이 파일과 최신 사용자 결정으로 관리한다.

## 목표

Boot에서 출발해 추후 별도 기획을 작성하고, 독립 프로젝트 또는 기술 데모 수준까지 발전시킨다. 어느 형태로 확정할지는 아직 결정하지 않았다.

2026-10-28 추가 결정: 공개 GitHub 저장소 `vosyd12/Rhythm`을 포트폴리오용 기술 데모의 기반으로 사용한다. 공개 소개는 현재 구현·검증 수준에 맞추며, 완성된 게임으로 표현하지 않는다.

## 아직 결정하지 않은 사항

- 최종 데모의 게임 규칙, 화면 구성, 콘텐츠·곡 범위, 배포 방식.
- 캠프·전투 의존 코드를 제거하거나 분리하는 방법과 시점.
- 전체 곡 정산 이후의 독립 데모 흐름. 현재 BaseCamp 복귀 기능을 임의로 대체하지 않는다.

이 항목들은 현재 결함 수정에 포함하지 않는다. 새 기획이 확정되면 관련 문서를 해당 분류 폴더에 추가하고 목록에 등록한다.

## 완료 판단

파일 존재, 컴파일, 실행 검증, 사용자 체감 평가를 구분한다. 수정마다 재현 방법·검증 결과·남은 한계를 기록하며, 데모 최종 완료는 사용자가 판단한다.
